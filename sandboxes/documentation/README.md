# Documentation sandboxes

Local environments for knowledge bases and wikis.

## Available

| Tool | Image | Notes |
|---|---|---|
| [confluence/](confluence/) | `atlassian/confluence:latest` | Full Confluence Server; requires one-time setup wizard (~5 min, free 30-day eval license) |

## Planned

| Tool | Self-host story |
|---|---|
| `outline/` | Outline is fully self-hostable (`outlinewiki/outline`) |
| `bookstack/` | BookStack ships an official Docker image |
| `mediawiki/` | The reference Wikipedia engine; trivial to spin up |
| `notion/` | No self-host — recorded HTTP fixtures only |
| `gitbook/` | Open-source CLI; no hosted instance |
