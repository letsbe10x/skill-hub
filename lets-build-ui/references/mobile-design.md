## Token Integration for Mobile

| Stack | Token Pattern |
|-------|--------------|
| Flutter | `ThemeData.colorScheme` + `TextTheme` — map Primary → `primary`, Accent → `secondary`, Background → `surface` |
| React Native + NativeWind | Theme context object — CSS vars not available; use `useTheme()` hook with typed color constants |
| SwiftUI | `Color` asset catalog in `Assets.xcassets` + `@Environment(\.colorScheme)` for dark mode |
| Jetpack Compose | `MaterialTheme.colorScheme` + `MaterialTheme.typography` — `dp` units, 4pt grid |
