# Accessibility quick checks (minimum bar)

## Keyboard + focus

- Tab order is logical; focus is visible.
- Modals/menus trap focus appropriately and return focus on close.
- Escape closes overlays (when appropriate).

## Semantics

- Buttons are buttons, links are links.
- Inputs have labels; helper/error text is connected (ARIA where needed).

## Contrast

- Text meets minimum contrast targets; don’t rely on “looks fine”.

## Motion

- Reduced motion is respected; avoid motion that causes disorientation.
