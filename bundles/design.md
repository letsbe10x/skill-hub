# Design bundle

Skills for UX research and content evaluation.

## Install

```bash
make design                                         # default IDE: claude
make design IDE=cursor                              # single IDE
make design IDE="claude cursor"                     # multiple IDEs
```

## Included skills

| Skill | Purpose |
|---|---|
| `lets-research-ux-walkthrough` | UX flow evaluation and improvement |
| `lets-research-content-evaluate` | Content quality and consistency review |

## Suggested companions

- `make pm` to capture upstream PRDs and opportunity maps.
- `make research` for competitive scanning + opportunity discovery.
